# STM32 项目源码导读

初次阅读可以从三条路径入手。

1. **看程序怎样启动**：应用启动汇编 → main.c → 三个 CreateTask 调用 → 调度器。
2. **跟一条控制命令**：bsp_uart.c 接收字节 → upper_cmd.c 解析命令 → vehicle_control.c 生成输出 → bsp_can.c 发送。
3. **跟一条健康报告**：VehicleTask 采集快照 → HealthTask 通过队列读取并编码 → VehicleTask 调用 Health_SendPending 发送。注意，函数名带 Task 也可能只是周期函数，例如 Vehicle_20msTask 由 VehicleTask 调用，共用后者的任务栈。

## Application/Core

| 文件 | 在本项目中的作用 |
|---|---|
| [main.c](../Application/Core/src/main.c) | 应用入口。main 初始化时钟、串口、CAN 和 TIM2，创建三个任务并启动调度器。VehicleTask 在这里协调通信轮询和 20 ms 控制周期。 |
| [stm32f4xx_it.c](../Application/Core/src/stm32f4xx_it.c) | 实现内核异常和部分中断入口。读 SysTick_Handler 可以看到 HAL 计时与 FreeRTOS 节拍怎样衔接。 |
| [stm32f4xx_it.h](../Application/Core/inc/stm32f4xx_it.h) | 声明中断处理函数。串口中断的实现位于 bsp_uart.c。 |
| [FreeRTOSConfig.h](../Application/Core/inc/FreeRTOSConfig.h) | 配置调度器，包括节拍频率、优先级数量、静态内存分配和断言。可对照 main.c 理解延时时间和任务优先级。 |
| [stm32f4xx_hal_conf.h](../Application/Core/inc/stm32f4xx_hal_conf.h) | 选择启用的 STM32 HAL 外设模块，并提供 HAL 使用的时钟等配置宏。 |

## Application/Board

| 文件 | 在本项目中的作用 |
|---|---|
| [bsp_uart.c](../Application/Board/bsp_uart.c) | 初始化串口，在接收中断中把字节存入环形缓冲区，供上位机和遥控协议模块稍后读取。 |

| [bsp_can.h](../Application/Board/bsp_can.h) | 声明 CAN 初始化和帧收发接口，供控制层和主循环调用。 |
| [bsp_eth.c](../Application/Board/bsp_eth.c) | 处理以太网接口、链路及网络报文，连接 UDP 数据与控制、遥测和 OTA 模块。 |
| [bsp_eth.h](../Application/Board/bsp_eth.h) | 声明以太网服务、报文处理、就绪状态和发送接口。 |

## Libraries 中的第三方源码

第三方库按组件阅读。Makefile 中的 SOURCES 和 HAL_MODULES 决定当前固件实际使用哪些实现。

| 组件 | 建议先看的内容 |
|---|---|
| CMSIS | core_cm4.h 提供 Cortex-M4 内核寄存器访问，stm32f407xx.h 定义芯片外设寄存器，system_stm32f4xx.c 提供系统初始化和时钟变量。 |
| STM32F4xx_HAL_Driver | Inc 放接口，Src 放实现。跟串口、CAN、以太网时，分别查 stm32f4xx_hal_uart.c、stm32f4xx_hal_can.c、stm32f4xx_hal_eth.c。 |
| FreeRTOS-Kernel | tasks.c 管理任务和调度，queue.c 实现队列，list.c 维护内核链表，portable/GCC/ARM_CM4F/port.c 连接调度器和 Cortex-M4F。 |
| Monocypher | monocypher.c 和 monocypher-ed25519.c 提供密码学实现。先读项目的 auth.c，可看到引导程序在哪里使用它们。 |
